How to export from Telegram
  1. Install Telegram Desktop (desktop.telegram.org) and log in. The phone apps and the App Store "Telegram for macOS" can't export this way.
  2. Open the chat (your DM with each other, and/or the group), click ⋮ → Export chat history.
  3. Untick photos, videos, voice messages, video messages, stickers, GIFs and files: only text is needed.
  4. Format: Machine-readable JSON. Set "from" to about 6 months ago if offered.
  5. Export. Telegram writes a folder with result.json; upload that file (or the zipped folder). Telegram may ask you to confirm on another device first.
  6. A full-account export (Settings → Advanced → Export Telegram data, JSON) works too; you'll pick the chats here.
